Resumo do que é Flexblox!

O Flexbox (abreviação de Flexible Box Layout) é um modelo de layout unidimensional do CSS projetado para ajudar a organizar, alinhar e distribuir o espaço entre elementos dentro de um contêiner, mesmo quando o tamanho deles é desconhecido ou dinâmico.

A sua principal vantagem é tornar o design responsivo e flexível. Ele permite que os elementos filhos se expandam para preencher o espaço disponível ou se encolham para evitar o transbordamento da tela.
